《暗牌禁咒》——Roguelike 卡牌构筑游戏（独立开发）

技术栈： Unity、C#、UGUI、ScriptableObject、Animator、Coroutine、状态机、策略模式

项目描述：
 独立开发类《杀戮尖塔》Roguelike卡牌构筑游戏，负责游戏架构设计、核心玩法开发及UI系统实现，历时3个月完成可玩版本。
 基于 ScriptableObject 搭建数据驱动配置架构，实现 50张卡牌、11种敌人、30种Buff、45种药水、23种遗物 等游戏配置解耦，支持低成本扩展新增内容。
 设计并实现卡牌战斗核心系统，包括抽牌堆、弃牌堆、消耗牌堆、能量管理、伤害结算、卡牌释放等完整战斗流程。
 基于有限状态机（FSM）构建回合制战斗框架，实现玩家回合、敌方回合、Buff结算及战斗结束等状态切换，提高战斗流程可维护性。
 基于策略模式封装Buff计算逻辑，实现持续伤害、护盾、增益等30种状态效果的叠加、持续回合及结算机制，降低新增Buff功能的耦合成本。
 使用UGUI完成战斗界面、地图界面及交互逻辑开发，结合Animator与Coroutine实现卡牌移动、攻击演出及UI动画效果。
 实现随机地图生成算法，支持战斗、精英、商店、宝箱、休息点等5类节点随机组合，构建探索→战斗→奖励→成长的完整游戏循环。
 
项目成果
 独立完成8个核心游戏系统开发，包括卡牌系统、Buff系统、回合系统、地图系统、奖励系统、敌人系统、UI系统及数据配置系统。
 实现50张卡牌、11种敌人、30种Buff、45种药水、23种遗物等完整游戏内容，形成可持续扩展的数据驱动架构。
 完成可独立运行的Roguelike卡牌构筑Demo，实现完整战斗闭环及多轮流程测试。
