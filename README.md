## 游戏简介

《牌咒》是一款回合制 Roguelike 卡牌构筑游戏。玩家通过选择岛屿、探索随机生成的地图节点，在战斗、商店、宝箱、休息点等事件中不断强化卡组，最终击败 Boss 解锁下一岛屿。

### 核心玩法循环

```
选择岛屿 → 探索节点地图 → 战斗/商店/宝箱/休息/随机事件
    → 获得卡牌/药水/遗物/金币 → 成长 → 击败 Boss → 解锁下一岛屿
```

### 战斗系统

- **回合制**：玩家回合 → 敌人回合交替进行
- **能量系统**：每回合 3 点能量（可通过 Buff/遗物提升）
- **卡牌堆机制**：抽牌堆、弃牌堆、消耗牌堆，手牌上限 10 张，基础抽牌 4 张
- **卡牌类型**：
  - **攻击卡**：点击敌人释放，支持多段攻击
  - **技能/法术卡**：向上拖拽释放
  - **能力卡**：一次性使用后消耗
- **升级系统**：卡牌实例级升级，可减少费用或增强效果
- **护盾机制**：格挡值先于血量承受伤害

### 元素亲和度系统（核心特色）

三种元素亲和度构筑差异化战斗风格：

| 元素 | 效果 | 上限 |
| --- | --- | --- |
| 🔥 火亲和度 | 每层法术伤害 +1 | 10 层（聚灵后 15 层） |
| ❄️ 冰亲和度 | 每层回合结束 +1 格挡 | 10 层（聚灵后 15 层） |
| ⚡ 电亲和度 | 每 2 层抽牌数 +1 | 10 层（聚灵后 15 层） |

## 技术架构

### 设计模式

| 模式 | 应用场景 |
| --- | --- |
| **有限状态机 (FSM)** | 战斗流程：Init → PlayerTurn → EnemyTurn → Win/Loss |
| **策略模式** | Buff 系统：48 种状态效果通过回调委托注入行为，新增 Buff 无需修改核心代码 |
| **数据驱动** | 所有卡牌、敌人、遗物、药水、关卡通过 ScriptableObject 配置，策划可独立编辑 |
| **单例模式** | 全局管理器（FightManager、EnemyManager、UIManager 等） |
| **事件驱动** | GameEvents 静态事件实现模块间解耦通信 |
| **反射工厂** | 敌人/遗物/药水通过 scriptName 反射实例化，扩展新内容零耦合 |

### 项目结构

```
Assets/
├── Scripts/                    # 核心 C# 脚本（214 个文件）
│   ├── Manager/                # 管理器层（战斗/敌人/卡牌/角色/音频/药水掉落）
│   ├── Fight/                  # 战斗状态机（FSM 各状态）
│   ├── Card/                   # 卡牌系统（攻击/法术/能力/诅咒）
│   ├── Buff/                   # Buff 状态系统（策略模式回调）
│   ├── Enemy/                  # 敌人 AI（11 种敌人行为）
│   ├── Map/                    # 随机地图生成与导航
│   ├── UI/                     # UGUI 界面系统
│   ├── Data/                   # ScriptableObject 数据定义
│   ├── Relics/                 # 遗物系统
│   ├── Potion/                 # 药水系统
│   └── GameApp.cs              # 游戏入口
├── Resources/                  # 运行时资源
│   ├── Date_Card/Card/         # 卡牌数据 (ScriptableObject)
│   ├── Data_Enemy/Enemies/     # 敌人数据
│   ├── Data_Relics/            # 遗物数据
│   ├── Date_Potion/            # 药水数据 (Common/Uncommon/Rare)
│   ├── Data_Ability/           # 状态能力配置
│   ├── Data_Level/             # 关卡配置
│   └── Prefabs/                # UI 预制体
├── Scenes/                     # 场景文件
│   └── GameRun.unity           # 主运行场景
├── Arts/                       # 美术资源（地牢场景/怪物模型）
└── [第三方插件]                 # DOTween / TextMesh Pro / Epic Toon FX 等
```

### 第三方依赖

| 插件 | 用途 |
| --- | --- |
| DOTween | 动画引擎（卡牌移动、UI 动效、摄像机震动） |

| Fire Creatures Pack | 火焰生物模型（8 种怪物） |
| Stylized Hand Painted Dungeon | 手绘地牢场景 |
| OneLine | 编辑器属性绘制扩展 |
